# FunnyFarm

Лабораторные работы по КПО. Вариант 3: Весёлая ферма
**Автор:** Цегельник Анастасия
**Вариант:** 3

## Описание

Консольная игра-симулятор фермы. Игрок ухаживает за животными, покупает новых, закупает еду и следит за сытостью питомцев.

## Лабораторные работы

| № | Тема | Тег |
|---|------|-----|
| 1 | Создание основы проекта. Главное меню, настройки | `v1.0` |
| 2 | Настройка взаимодействия с файлами. Map животных | `v2.0` |
| 3 | Создание ключевых функций. Классы Animal, Food, Player, Game | `v3.0` |
| 4 | Система сохранений и загрузок. SaveManager, автосохранение | `v4.0` |
| 5 | Расширение функциональности. Счастье, продукция, доход | `v5.0` |
| 6 | Красивый интерфейс. ConsoleUI, рамки, цвета | `v6.0` |

## Как смотреть версии

- **Текущая версия** — в ветке `main`.
- **Версии лаб** — по тегам `v1.0`–`v6.0`.

## Сборка

1. Открыть `FunnyFarm.sln` в Visual Studio.
2. Собрать: `Ctrl+Shift+B`.
3. Запустить: `Ctrl+F5`.

## Управление

- **1** — начать игру.
- **2** — загрузить игру.
- **3** — настройки.
- **4** — о программе.
- **5** — выход.

## Технологии

- **Язык:** C++
- **Среда:** Visual Studio
- **Стандарт:** C++14
