# FunnyFarm

Лабораторные работы по КПО. Вариант 3: «Весёлая ферма».
**Автор:** Цегельник Анастасия

## Описание

Консольная игра-симулятор фермы на C++. Игрок ухаживает за животными, покупает новых, закупает еду, следит за сытостью и счастьем питомцев, продаёт продукцию.
